# 《织》— Type Help 风格解谜游戏原型

一款受 [Type Help](https://william-rous.itch.io/type-help) 启发的**文字侦探解谜游戏**原型，探讨人工智能与人类之间的情感关系。

玩家进入一个受损的 AI 操作系统界面，通过搜索日志、推理文件名来还原一桩发生在山中宅邸"归墟苑"的集体死亡案件。

## 在线试玩

纯前端项目，无需安装任何依赖。以下两种方式任选：

### 方式一：直接双击打开（最简单）

1. 下载或克隆本仓库
2. 双击 `index.html` 即可在浏览器中游玩

### 方式二：启动本地服务器

如果双击打开后遇到资源加载问题，可以用任意本地服务器：

```bash
# Python（大多数系统自带）
cd type-help-prototype
python -m http.server 8123

# 或者用 Node.js
npx serve .
```

然后在浏览器打开 [http://localhost:8123](http://localhost:8123)

## 怎么玩（示例案件）

游戏界面左侧是命令行终端，右侧是场景图片与已解锁文件列表。

### 基本命令

| 命令 | 作用 |
|------|------|
| `help` | 显示帮助 |
| `list` | 列出已解锁文件 |
| `name 2 里德` | 给 2 号人物标注名字 |
| `intro` | 重看案情开场 |
| `solve` | 解锁全部文件后给出结论 |
| `clear` | 清屏 |

### 文件名格式

```
时间-地点代码-在场人物编号
```

例如 `02-DI-1-3-4` 表示第 2 时段、餐厅、1 号 3 号 4 号在场。

- 地点代码：`EN` 门厅、`DI` 餐厅、`LI` 书房、`GA` 花园
- 人物顺序随意，大小写不敏感，猜错无惩罚

### 通关路径

读转录中"谁去了哪个房间"的线索，推理出下一份文件名并输入解锁。
